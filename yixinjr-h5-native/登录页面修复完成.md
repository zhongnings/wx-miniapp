## 🔍 调试技巧

### 如果文字还是不换行：

1. **打开开发者工具（F12）**
2. **选择 Elements 标签**
3. **找到 `.agreement-text` 元素**
4. **查看 Computed 样式：**
   - `white-space` 应该是 `normal`
   - `word-wrap` 应该是 `break-word`
   - `display` 应该是 `block` 或 `flex`

5. **如果样式不对，检查是否有其他样式覆盖**

### 如果 checkbox 还是不显示：

1. **打开开发者工具（F12）**
2. **选择 Elements 标签**
3. **找到 `uni-checkbox` 元素**
4. **查看 Computed 样式：**
   - `display` 不应该是 `none`
   - `opacity` 不应该是 `0`
   - `width` 和 `height` 应该大于 0

5. **查看 `.uni-checkbox-input` 的样式**
   - 应该有边框 `border: 1px solid #d1d1d1`
   - 应该有宽高 `width: 18px; height: 18px`

### 如果协议文档还是404：

1. **打开开发者工具（F12）**
2. **选择 Console 标签**
3. **点击协议链接，查看日志输出**
4. **选择 Network 标签**
5. **查看请求的 URL 是否正确：**
   - 应该是：`http://localhost:8080/static/agreements/user-agreement.docx`
   - 不应该是：`http://localhost:8081/agreements/user-agreement.docx`

6. **检查文件是否存在：**
   ```bash
   dir "D:\workcode\miniapp\yixinjr-h5-native\static\agreements"
   ```

## 💡 经验总结

### H5 和小程序的主要差异：

1. **文本渲染**
   - 小程序：`<text>` 标签自动换行
   - H5：需要显式设置 `white-space: normal`

2. **checkbox 组件**
   - 小程序：原生组件，自动显示
   - H5：需要设置样式才能显示

3. **静态资源访问**
   - 小程序：可以访问后端资源
   - H5：建议放在前端 `static` 目录

4. **布局对齐**
   - 小程序：`align-items: center` 通常没问题
   - H5：多行文本需要 `align-items: flex-start`
