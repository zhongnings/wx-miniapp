## 统一修复模式

### 在每个页面的 onLoad 方法中添加：

```javascript
onLoad() {
  // H5平台使用固定值
  // #ifdef H5
  this.statusBarHeight = 0;
  this.navBarHeight = 44;
  // #endif
  
  // 非H5平台获取系统信息
  // #ifndef H5
  const systemInfo = uni.getSystemInfoSync();
  this.statusBarHeight = systemInfo.statusBarHeight || 0;
  this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
  // #endif
  
  // 其他原有代码...
}
```

### 在每个页面的 <style> 中添加：

```css
/* H5平台样式适配 */
/* #ifdef H5 */
.navbar {
  height: 44px !important;
  padding-top: 0 !important;
}

.search-section,
.tabs-section,
.filter-section {
  padding-top: 0;
}

.content-area,
.order-list,
.scroll-view {
  height: auto;
  min-height: calc(100vh - 44px - 100px);
}

.input-wrapper {
  min-height: 48px;
}

.form-input {
  -webkit-appearance: none;
  outline: none;
}

button::after {
  border: none !important;
}
/* #endif */
```

## 快速修复方法

### 方法1：手动逐个修复（推荐，更安全）

按照上面的模式，打开每个文件，添加对应的代码。

### 方法2：使用编辑器批量查找替换

#### 步骤1：修复 onLoad 方法

**在 VSCode/Cursor 中：**
1. 按 Ctrl+Shift+F 打开全局搜索
2. 搜索范围：`pages/order/**/*.vue`
3. 查找：
```
const systemInfo = uni.getSystemInfoSync();
```

4. 在每个匹配的文件中，将：
```javascript
const systemInfo = uni.getSystemInfoSync();
this.statusBarHeight = systemInfo.statusBarHeight || 0;
this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
```

替换为：
```javascript
// #ifdef H5
this.statusBarHeight = 0;
this.navBarHeight = 44;
// #endif

// #ifndef H5
const systemInfo = uni.getSystemInfoSync();
this.statusBarHeight = systemInfo.statusBarHeight || 0;
this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
// #endif
```

#### 步骤2：添加H5样式

在每个订单相关页面的 `</style>` 标签前添加H5适配样式。
