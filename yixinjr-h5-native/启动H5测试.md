## 🐛 如果还有样式问题

### 常见问题排查

#### 1. 样式没有生效
**检查：**
- 浏览器缓存：按 Ctrl+Shift+R 强制刷新
- 条件编译：确认是H5平台
- CSS文件路径：检查 `common/h5-fix.css` 是否存在

**解决：**
```bash
# 清除缓存重新编译
npm run clean
npm run dev:h5
```

#### 2. 导航栏高度还是不对
**检查：**
- 打开开发者工具
- 检查 `.navbar` 元素的计算样式
- 查看是否有其他样式覆盖

**解决：**
在对应页面的 `<style scoped>` 中添加：
```css
/* #ifdef H5 */
.navbar {
  height: 44px !important;
}
/* #endif */
```

#### 3. 输入框样式异常
**检查：**
- 浏览器默认样式是否被清除
- placeholder 颜色是否可见

**解决：**
```css
/* #ifdef H5 */
.form-input {
  -webkit-appearance: none;
  border: none;
  outline: none;
  background: transparent;
}
/* #endif */
```

#### 4. 按钮有边框
**检查：**
- button::after 伪元素

**解决：**
```css
/* #ifdef H5 */
button::after {
  border: none !important;
}
/* #endif */
```

## 🔧 进一步优化

### 如果需要修复其他页面

以**订单列表页面**为例：

1. **打开文件**：`pages/order/list/index.vue`

2. **在 `<script>` 的 `onLoad` 中添加**：
```javascript
onLoad() {
  // #ifdef H5
  this.statusBarHeight = 0;
  this.navBarHeight = 44;
  // #endif
  
  // #ifndef H5
  const systemInfo = uni.getSystemInfoSync();
  this.statusBarHeight = systemInfo.statusBarHeight || 0;
  this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
  // #endif
  
  // 其他代码...
}
```

3. **在 `<style>` 中添加**：
```css
/* #ifdef H5 */
.navbar {
  height: 44px;
  padding-top: 0;
}

.content-area {
  height: calc(100vh - 44px);
}
/* #endif */
```

### 批量修复脚本

如果有很多页面需要修复，可以使用查找替换：

**查找：**
```javascript
const systemInfo = uni.getSystemInfoSync();
this.statusBarHeight = systemInfo.statusBarHeight || 0;
this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
```

**替换为：**
```javascript
// #ifdef H5
this.statusBarHeight = 0;
this.navBarHeight = 44;
// #endif

// #ifndef H5
const systemInfo = uni.getSystemInfoSync();
this.statusBarHeight = systemInfo.statusBarHeight || 0;
this.navBarHeight = (systemInfo.statusBarHeight || 0) + 44;
// #endif
```

## 📊 性能优化建议

### 1. 启用生产模式构建
```bash
npm run build:h5
```
生成的文件在 `unpackage/dist/build/h5/`

### 2. 配置 CDN 加速
在 `manifest.json` 的 `h5` 配置中：
```json
{
  "h5": {
    "publicPath": "https://your-cdn.com/",
    "optimization": {
      "treeShaking": {
        "enable": true
      }
    }
  }
}
```

- 压缩图片大小
