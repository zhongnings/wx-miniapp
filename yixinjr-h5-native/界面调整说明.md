# 界面调整说明

## 修改日期
2026年1月27日

## 修改内容

### 1. 后退按钮图标统一调整
将所有页面的后退按钮从箭头符号 `〈` 改为 `<` 符号，并统一样式。

#### 修改的页面：
- ✅ 登录页面 (`pages/login/index.vue`)
- ✅ 注册页面 (`pages/register/index.vue`)
- ✅ 订单详情页面 (`pages/order/detail/index.vue`)
- ✅ 合同协议页面 (`pages/order/contracts/index.vue`)

#### 样式调整：
```css
.navbar-icon {
  font-size: 40rpx;
  font-weight: bold;
  color: #333; /* 或 #ffffff，根据背景色调整 */
}
```

### 2. 登录页面复选框选中状态优化
为"我已知晓"复选框的选中状态添加背景色，同时保留打钩图标。

#### 修改位置：
- 文件：`pages/login/index.vue`
- 样式部分：`.agreement-checkbox`

#### 新增样式：
```css
.agreement-checkbox {
  margin-right: 16rpx;
  margin-top: 4rpx;
  flex-shrink: 0;
  transform: scale(1.2);
}

/* 复选框选中状态样式 */
checkbox .wx-checkbox-input.wx-checkbox-input-checked,
checkbox .uni-checkbox-input.uni-checkbox-input-checked {
  background-color: #ff6f6f !important;
  border-color: #ff6f6f !important;
  color: #ffffff !important;
}

/* H5平台复选框选中样式 */
input[type="checkbox"]:checked {
  background-color: #ff6f6f !important;
  border-color: #ff6f6f !important;
}
```

## 效果说明

### 后退按钮
- 图标从 `〈` 改为 `<`
- 字体大小：40rpx
- 字体加粗
- 颜色根据背景自适应（白色背景用深色，红色背景用白色）

### 复选框
- 未选中：白色背景，灰色边框
- 选中后：红色背景（#ff6f6f），白色打钩图标
- 尺寸放大1.2倍，更易点击
