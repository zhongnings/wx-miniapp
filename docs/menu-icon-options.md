# 菜单图标选项

以下是多个菜单图标选项，你可以选择喜欢的图标替换到代码中。

## 图标选项

### 1. 三横线（汉堡菜单）
```
☰
```
**使用场景**：最常见的菜单图标，简洁明了
**代码位置**：`pages/account/list/index.wxml` 和 `pages/order/list/index.wxml`

### 2. 房子图标
```
🏠
```
**使用场景**：表示主页或首页
**当前使用**：订单列表页面

### 3. 网格图标
```
▦
```
**使用场景**：表示应用菜单或功能列表

### 4. 圆点菜单
```
⋮
```
**使用场景**：垂直三点菜单，常用于更多选项

### 5. 列表图标
```
≡
```
**使用场景**：表示列表或菜单

### 6. 齿轮图标
```
⚙
```
**使用场景**：表示设置或配置

### 7. 星形图标
```
★
```
**使用场景**：表示收藏或重要功能

### 8. 文件夹图标
```
📁
```
**使用场景**：表示文件管理或分类

### 9. 导航图标
```
🧭
```
**使用场景**：表示导航或菜单

### 10. 书签图标
```
🔖
```
**使用场景**：表示标签或分类

## 如何替换图标

### 方法1：修改资金账户列表页面
文件：`wx-miniapp/miniprogram/pages/account/list/index.wxml`

找到第4行：
```xml
<text class="icon-text">☰</text>
```

将 `☰` 替换为你喜欢的图标即可。

### 方法2：修改订单列表页面
文件：`wx-miniapp/miniprogram/pages/order/list/index.wxml`

找到第7行：
```xml
<text class="icon-text">🏠</text>
```

将 `🏠` 替换为你喜欢的图标即可。

## 推荐组合

### 组合1：统一使用三横线
- 订单列表：`☰`
- 资金账户：`☰`
- **优点**：统一风格，用户习惯

### 组合2：区分功能
- 订单列表：`🏠`（主页）
- 资金账户：`☰`（菜单）
- **优点**：功能区分明确

### 组合3：现代简约
- 订单列表：`≡`
- 资金账户：`≡`
- **优点**：简洁现代

### 组合4：图形化
- 订单列表：`📋`（订单）
- 资金账户：`💳`（账户）
- **优点**：直观易懂

## 浮动按钮图标选项

### 当前使用
- 订单列表：`✓`（对勾）
- 资金账户：`+`（加号）

### 其他选项
1. `➕` - 加号（更明显）
2. `✚` - 十字加号
3. `⊕` - 圆圈加号
4. `🆕` - NEW标志
5. `📝` - 记事本（表示新建）

## 修改示例

### 示例1：将资金账户菜单图标改为网格
```xml
<!-- 修改前 -->
<text class="icon-text">☰</text>

<!-- 修改后 -->
<text class="icon-text">▦</text>
```

### 示例2：将浮动按钮图标改为圆圈加号
```xml
<!-- 修改前 -->
<text class="fab-icon">+</text>

<!-- 修改后 -->
<text class="fab-icon">⊕</text>
```

## 注意事项

1. **字体支持**：确保选择的图标在微信小程序中能正常显示
2. **大小调整**：如果图标显示过大或过小，可以在 wxss 文件中调整 `font-size`
3. **颜色**：图标颜色由 CSS 的 `color` 属性控制
4. **对齐**：某些图标可能需要调整 `line-height` 或使用 flexbox 居中

## 样式调整

如果图标显示不理想，可以在对应的 wxss 文件中调整：

```css
.icon-text {
  font-size: 40rpx;  /* 调整大小 */
  color: #fff;       /* 调整颜色 */
  line-height: 1;    /* 调整行高 */
}
```
