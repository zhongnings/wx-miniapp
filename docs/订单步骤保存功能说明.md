# 订单步骤保存功能说明

## 功能概述

实现了订单创建流程中每个步骤（step1-step6）的独立保存功能，支持用户随时保存当前步骤的数据，并在订单详情页查看已保存的信息。

## 数据库设计

### 1. 订单表（t_order）更新

新增字段：
- `user_id`: 用户ID（微信openid或其他标识）
- `step1_saved_at`: 步骤1保存时间
- `step2_saved_at`: 步骤2保存时间
- `step3_saved_at`: 步骤3保存时间
- `step4_saved_at`: 步骤4保存时间
- `step5_saved_at`: 步骤5保存时间
- `step6_saved_at`: 步骤6保存时间

### 2. 借款人信息表（t_order_borrower）

已包含身份证图片URL字段：
- `face_front_url`: 身份证正面图片URL
- `face_back_url`: 身份证反面图片URL

## API接口

### 保存订单步骤数据

**接口地址：** `POST /public/orders/{id}/steps`

**请求参数：**
```json
{
  "orderId": 1,
  "step": 2,
  "data": {
    "name": "张三",
    "idNumber": "360423198908141319",
    "idFrontImage": "http://example.com/id-front.jpg",
    "idBackImage": "http://example.com/id-back.jpg",
    ...
  }
}
```

**响应：** 200 OK

## 前端使用说明

### 1. 保存步骤数据

在每个步骤页面（step1-step6）中，调用保存接口：

```javascript
// 保存步骤2数据
const req = wx.$request || require('../../../../utils/request');
req.post(`/public/orders/${orderId}/steps`, {
  orderId: orderId,
  step: 2,
  data: {
    name: this.data.formData.name,
    idNumber: this.data.formData.idNumber,
    idFrontImage: this.data.formData.idFrontImage,
    idBackImage: this.data.formData.idBackImage,
    // ... 其他字段
  }
}).then(res => {
  wx.showToast({
    title: '保存成功',
    icon: 'success'
  });
});
```

### 2. 订单详情页显示身份证图片

在订单详情页的借款人信息页面（step2），如果存在身份证图片URL，会自动显示：

- 身份证正面：`formData.idFrontImage`
- 身份证反面：`formData.idBackImage`

图片支持点击预览功能。

## 使用示例

### 1. 保存步骤2数据（借款人信息）

```javascript
// 在 step2/index.js 的保存方法中
saveStep2Data() {
  const orderId = this.data.orderId;
  if (!orderId) {
    wx.showToast({
      title: '订单ID不存在',
      icon: 'none'
    });
    return;
  }

  const req = wx.$request || require('../../../../utils/request');
  req.post(`/public/orders/${orderId}/steps`, {
    orderId: orderId,
    step: 2,
    data: this.data.formData
  }).then(res => {
    wx.showToast({
      title: '保存成功',
      icon: 'success'
    });
  }).catch(err => {
    wx.showToast({
      title: '保存失败',
      icon: 'none'
    });
  });
}
```

### 2. 查看模式加载数据

在查看模式下，会自动从订单详情接口加载数据：

```javascript
// step2/index.js 的 onLoad 方法中已实现
if (mode === 'view') {
  this.loadBorrowerInfoFromOrder(orderId);
}
```

## 注意事项

1. **图片上传**：身份证图片需要先上传到服务器，获取URL后再保存到数据库
2. **数据格式**：保存的数据格式需要与前端表单字段对应
3. **用户ID**：需要在创建订单时设置 `user_id` 字段
4. **事务处理**：步骤保存使用事务，确保数据一致性
