# 微信小程序包大小优化方案

## 📊 当前包大小分析

### 主要占用空间的文件：
1. **region-picker.js（省市区选择器）：108KB** ⚠️ 最大单文件
2. **银行图标（23个PNG）：约195KB**
3. **其他JS/WXML/WXSS文件：待统计**

## 🎯 优化建议（按优先级）

### ✅ 优先级1：省市区数据迁移到后端（预计减少 100KB+）

**当前问题：**
- `region-picker.js` 包含完整的省市区三级数据硬编码在前端
- 数据量大（约3000+条记录），占用108KB

**解决方案：**
已为你创建完整的后端方案：

#### 1. 数据库设计
- ✅ 已创建 `region` 表结构
- ✅ 已提供示例数据SQL（`src/main/resources/db/region_data.sql`）

#### 2. 后端接口
- ✅ `RegionController.java` - 提供4个接口：
  - `GET /public/regions/provinces` - 获取省份列表
  - `GET /public/regions/cities?provinceCode=xxx` - 获取城市列表
  - `GET /public/regions/districts?cityCode=xxx` - 获取区县列表
  - `GET /public/regions/search?keyword=xxx` - 搜索地区
- ✅ `RegionService.java` - 业务逻辑（带缓存优化）
- ✅ `Region.java` - 实体类
- ✅ `RegionMapper.java` - 数据访问层

#### 3. 完整数据获取渠道
由于完整数据约3000+条，建议从以下渠道获取：

**推荐方案1：GitHub开源数据（最简单）**
```bash
# 下载完整的省市区JSON数据
https://github.com/modood/Administrative-divisions-of-China
# 包含：省市区三级数据、拼音、区号等
```

**推荐方案2：国家统计局官网**
```
http://www.stats.gov.cn/sj/tjbz/tjyqhdmhcxhfdm/
# 最权威，但需要爬虫采集
```

**推荐方案3：高德地图API**
```
https://lbs.amap.com/api/webservice/guide/api/district
# 实时数据，可通过API获取
```

#### 4. 前端改造（需要修改 region-picker.js）
将硬编码数据改为API调用：

```javascript
// 修改前（硬编码）
initProvinceList() {
  const provinces = [
    { code: '110000', name: '北京', pinyin: 'beijing' },
    // ... 3000+ 条数据
  ];
}

// 修改后（API调用）
initProvinceList() {
  wx.request({
    url: '/public/regions/provinces',
    success: (res) => {
      this.setData({ provinces: res.data });
    }
  });
}
```

### ✅ 优先级2：银行图标优化（预计减少 100-150KB）

**当前问题：**
- 23个PNG图标，总计约195KB
- 每个图标约8-10KB

**解决方案（3选1）：**

#### 方案A：使用IconFont字体图标（推荐）
- 将所有银行图标转为字体文件
- 整个字体文件仅需 20-30KB
- 支持颜色自定义、缩放无损

#### 方案B：使用SVG图标
- 将PNG转为SVG
- 体积减少60-80%
- 支持颜色自定义

#### 方案C：图标CDN化
- 将图标上传到CDN
- 小程序动态加载（需要配置域名白名单）
- 完全不占用包体积

### ✅ 优先级3：代码分包（预计优化体验）

**微信小程序分包规则：**
- 主包限制：2MB
- 单个分包限制：2MB
- 总包限制：20MB

**建议分包策略：**

```json
// app.json
{
  "pages": [
    "pages/home/index",
    "pages/login/index"
  ],
  "subpackages": [
    {
      "root": "pages/order",
      "name": "order",
      "pages": [
        "create/step1/index",
        "create/step2/index",
        "detail/index",
        "list/index"
      ]
    },
    {
      "root": "pages/admin",
      "name": "admin",
      "pages": [
        "settings/index",
        "profile/index"
      ]
    }
  ],
  "preloadRule": {
    "pages/home/index": {
      "network": "all",
      "packages": ["order"]
    }
  }
}
```
