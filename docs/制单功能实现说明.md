# 制单功能实现说明

## 功能概述

实现了订单风控审核通过后的制单流程，包括：
1. 风控审核中状态显示"通过"和"驳回"按钮
2. 通过审核后进入待放款状态
3. 待放款状态显示制单信息模块
4. 制单列表、新增制单、选择收款方功能

## 数据库变更

### 1. 添加收款方类型字段

执行 SQL：
```sql
ALTER TABLE t_order_voucher ADD COLUMN payee_type VARCHAR(32) COMMENT '收款方类型：borrower/coBorrower/guarantor' AFTER payee;
```

文件位置：`docs/db/add-voucher-payee-type.sql`

## 后端实现

### 1. 实体类
- `OrderVoucher.java` - 制单信息实体

### 2. Mapper
- `OrderVoucherMapper.java` - 制单信息 Mapper

### 3. Service
- `OrderVoucherService.java` - 制单服务接口
- `OrderVoucherServiceImpl.java` - 制单服务实现
  - `listByOrderId()` - 获取订单的制单列表
  - `getPayeeList()` - 获取收款方列表（借款人、共借人、担保人的银行卡）
  - `addVoucher()` - 新增制单
  - `deleteVoucher()` - 删除制单
  - `getLimitInfo()` - 获取制单限额信息

### 4. Controller
- `OrderVoucherController.java` - 制单信息控制器
  - `GET /public/orders/{orderId}/vouchers` - 获取制单列表
  - `GET /public/orders/{orderId}/vouchers/payees` - 获取收款方列表
  - `GET /public/orders/{orderId}/vouchers/limit` - 获取限额信息
  - `POST /public/orders/{orderId}/vouchers` - 新增制单
  - `DELETE /public/orders/{orderId}/vouchers/{id}` - 删除制单

### 5. 订单服务扩展
- `OrderService.approve()` - 通过风控审核接口
- `OrderController.approve()` - 通过审核 API：`POST /public/orders/{id}/approve`

## 前端实现

### 1. 制单列表页面
**路径：** `pages/order/voucher-list/`

**功能：**
- 显示制单限额提示（单笔500万、单日3000万、单月1亿）
- 显示制单列表（金额、收款方、开卡银行、银行卡号）
- 空状态提示
- "查看收款卡"按钮 - 跳转到银行卡信息页面
- "新增制单"按钮 - 跳转到新增制单页面

### 2. 新增制单页面
**路径：** `pages/order/voucher-add/`

**功能：**
- 金额输入（默认为借款金额，禁用编辑）
- 选择收款方（点击跳转到收款方选择页面）
- 收款方类型（自动识别）
- 开卡银行（自动识别）
- 银行卡号（自动识别）
- 提交按钮

### 3. 选择收款方页面
**路径：** `pages/order/payee-select/`

**功能：**
- 显示所有收款方列表（借款人、共借人、担保人的银行卡信息）
- 每个收款方显示：姓名、开卡银行、银行卡号
- 点击选择后自动填充到新增制单页面并返回

### 4. 订单详情页面更新
**路径：** `pages/order/detail/`

**更新内容：**
- 风控审核中状态（orderStatus=3）：显示"驳回"和"通过"两个按钮
- 待放款状态（orderStatus=4）：显示"制单信息"模块
- 点击"通过"按钮：调用审核通过接口，订单状态变为待放款
- 点击"制单信息"：跳转到制单列表页面

## 订单状态流转

```
0. 待提交
   ↓ (提交)
1. 签署中
   ↓ (签署完成)
3. 风控审核中 ← 当前新增功能
   ↓ (通过)     ↓ (驳回)
4. 待放款      0. 待提交
   ↓
5. 放款中
   ↓
6. 完成
```

## API 接口

### 1. 通过风控审核
```
POST /public/orders/{id}/approve
```

**功能：** 将订单从"风控审核中"状态改为"待放款"状态

**响应：** 200 OK

## 使用流程

1. **订单提交** → 进入"签署中"状态
2. **签署完成** → 进入"风控审核中"状态
3. **风控审核** → 在订单详情页显示"驳回"和"通过"按钮
4. **点击通过** → 订单进入"待放款"状态
5. **待放款状态** → 显示"制单信息"模块
6. **点击制单信息** → 进入制单列表页面
7. **点击新增制单** → 进入新增制单页面
8. **选择收款方** → 从借款人/共借人/担保人的银行卡中选择
9. **提交制单** → 制单信息保存成功

## 注意事项

1. **数据库字段：** 需要执行 SQL 添加 `payee_type` 字段
2. **收款方来源：** 从 `t_order_bank_card` 表获取所有银行卡信息
3. **金额默认值：** 新增制单时金额默认为订单的借款金额
4. **自动识别：** 选择收款方后，收款方类型、开卡银行、银行卡号自动填充
5. **状态判断：** 
   - orderStatus = 3：风控审核中，显示"通过"和"驳回"按钮
   - orderStatus = 4：待放款，显示"制单信息"模块
