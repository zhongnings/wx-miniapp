# 微信小程序调试技巧示例

## 一、基础调试

### 1. 查看页面数据
在 Console 中执行：
```javascript
// 获取当前页面
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];

// 查看页面数据
console.log('页面数据:', currentPage.data);

// 查看页面方法
console.log('页面方法:', Object.keys(currentPage));
```

### 2. 修改页面数据（实时预览）
```javascript
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];

// 修改数据
currentPage.setData({
  testValue: '这是测试值',
  orders: [{ id: 1, name: '测试订单' }]
});
```

### 3. 调用页面方法
```javascript
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];

// 调用页面方法
currentPage.loadOrders();
currentPage.onSubmit({ detail: { value: { username: 'test', password: '123' } } });
```

## 二、网络请求调试

### 1. 查看所有请求
在 Network 标签中：
- 查看请求 URL、方法、状态码
- 查看请求头和请求体
- 查看响应头和响应体
- 查看请求耗时

### 2. 拦截请求（在代码中）
```javascript
// utils/request.js
function request(options) {
  // 添加请求拦截
  console.group('📤 请求发送');
  console.log('URL:', `${BASE_URL}${options.url}`);
  console.log('Method:', options.method);
  console.log('Data:', options.data);
  console.log('Time:', new Date().toLocaleTimeString());
  console.groupEnd();

  return wx.request({
    ...options,
    success: (res) => {
      // 添加响应拦截
      console.group('📥 响应接收');
      console.log('URL:', `${BASE_URL}${options.url}`);
      console.log('Status:', res.statusCode);
      console.log('Data:', res.data);
      console.log('Time:', new Date().toLocaleTimeString());
      console.groupEnd();

      options.success && options.success(res);
    }
  });
}
```

### 3. 模拟请求响应
```javascript
// 在 Console 中模拟响应
const mockResponse = {
  statusCode: 200,
  data: {
    token: 'MOCK_TOKEN',

  }

// 在页面中处理模拟响应
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];
currentPage.onLoginSuccess(mockResponse);
```

## 三、存储调试

### 1. 查看所有存储
```javascript
// 在 Console 中执行
const storageInfo = wx.getStorageInfoSync();
console.log('存储信息:', storageInfo);

// 查看所有 key
storageInfo.keys.forEach(key => {
  const value = wx.getStorageSync(key);
  console.log(`${key}:`, value);
});
```

### 2. 清除存储
```javascript
// 清除所有
wx.clearStorageSync();

// 清除特定 key
wx.removeStorageSync('TOKEN');
wx.removeStorageSync('roles');
```

### 3. 修改存储
```javascript
// 直接修改存储值
wx.setStorageSync('TOKEN', 'NEW_TOKEN');
wx.setStorageSync('testData', { key: 'value' });
```

```javascript
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];

// 重新加载数据
if (currentPage.onLoad) {
  currentPage.onLoad(currentPage.options || {});
}

// 或调用特定方法
if (currentPage.loadOrders) {
  currentPage.loadOrders();
}
```

## 五、错误调试

### 1. 捕获全局错误
在 `app.js` 中添加：
```javascript
// 捕获未处理的 Promise 错误
wx.onUnhandledRejection((res) => {
  console.error('未处理的 Promise 错误:', res);
  // 可以上报错误
});

// 捕获页面错误
wx.onError((error) => {
  console.error('页面错误:', error);
  // 可以上报错误
});
```

### 2. 调试特定功能
```javascript
// 在页面 JS 中添加调试代码
onLoad() {
  // 开启调试模式
  if (this.debug) {
    console.log('页面加载，参数:', options);
    console.log('当前数据:', this.data);
  }
  
  // 使用 try-catch 捕获错误
  try {
    this.loadData();
  } catch (error) {
    console.error('加载数据失败:', error);
    wx.showToast({
      title: '加载失败',
      icon: 'none'
    });
  }
}
```

## 七、实用调试代码片段

### 1. 快速查看当前状态
```javascript
// 保存为全局函数，在 Console 中随时调用
window.debug = function() {
  const pages = getCurrentPages();
  const currentPage = pages[pages.length - 1];
  const storage = wx.getStorageInfoSync();
  
  return {
    当前页面: currentPage.route,
    页面数据: currentPage.data,
    存储数据: storage.keys.reduce((acc, key) => {
      acc[key] = wx.getStorageSync(key);
      return acc;
    }, {}),
    页面栈: pages.map(p => p.route)
  };
};

// 使用：在 Console 中输入 debug()
```

### 2. 快速测试 API
```javascript
// 在 Console 中测试 API
const req = require('./utils/request');

req.request({
  url: '/auth/public-key',

}).catch(err => {
  console.error('API 测试失败:', err);
});
```

### 3. 批量操作

1. 查看 Console 错误信息

## 十、调试最佳实践

1. **使用日志工具**：统一使用 `logger.js` 输出日志
2. **添加调试开关**：通过环境变量控制是否输出详细日志
3. **错误处理**：所有异步操作都要有错误处理
4. **数据验证**：在关键位置验证数据格式
5. **性能监控**：关注请求耗时和页面渲染性能
